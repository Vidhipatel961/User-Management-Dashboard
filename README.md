# User Management Dashboard

## Tech Stack
- React.js (Vite)
- ASP.NET Core 8 Web API
- Entity Framework Core (InMemory)
- Bootstrap
- Docker

## Features
- CRUD users
- Search by name
- Validation (frontend & backend)
- Toast notifications
- Responsive UI
